# Amazon E-Commerce Sales Analytics Dashboard

## Project Overview

This project analyzes Amazon e-commerce sales data using Power BI to understand sales performance, revenue trends, order activity, and business performance.

## Objectives

* Analyze total revenue and profit.
* Track order and sales performance.
* Identify important sales trends.
* Present business insights through an interactive dashboard.

## Tools Used

* Power BI
* DAX
* Data Cleaning and Data Visualization

## Key Metrics

* Total Revenue: ₹78.59M
* Total Profit: ₹25.76M
* Profit Margin: 32.78%
